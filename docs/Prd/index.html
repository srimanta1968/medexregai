Key decisions in this set

  1. Compete on intelligence, not on record-keeping. Veeva's videos show no predicate, pathway or precedent intelligence, and that's where the consultant's hours go.
  2. Registers, not repositories. Adopt Veeva's content-plan, continuous-check, HA-question and chronology patterns in light form. Never store or file the submission itself.
  3. Prove research savings first. The Submission Workspace is built only if the week-12 gate shows a ≥ 50% saving on predicate and research work.
  4. One build serves the pilot and the market. Pilot features become the month-6 baseline; the content checklist and gap audit move forward from Release 2.
  5. New requirement group FR-13 "Submission Workspace" (FR-13.1–13.10) to be added to MRA-REQ-001.
