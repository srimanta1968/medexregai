3. Technical spike: eSTAR XML (1 week)

FDA says data can be exported from an older eSTAR as XML and imported to a new version in Acrobat Pro, without attachments. We need to know whether generated XML can pre-fill a template reliably.

QuestionPass
Can we generate XML that imports into a blank nIVD v7.1 template?Fields fill with no errors, and the form's own logic still runs and reports status correctly
How stable is the schema between versions?Mapping can be versioned, and version changes do not break it silently
Is this acceptable to consultants and FDA's process?A consultant can review and finish the form as usual; check FDA's template instructions for any restriction

If it fails, keep the Word and readiness outputs and leave form-filling to the consultant. MedexRegAI still never files.

AreaChange

Data model (§6)New: SourceLocation, ClientFile, FileVersion, Contradiction, InfoRequest, SectionDraft, DraftStatement. Device gets a stable identity for later UDI linkage.
