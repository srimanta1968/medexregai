What MedexRegAI would look like, phase by phase

Concept screens for each build phase of PRD v2.0. They show what a consultant would see and do: from connecting a client folder in the first phase, to reviewing drafted eSTAR sections in Word, to the wider workspace later. Nothing here is built yet. We are showing it so you can tell us what is wrong before we build it.

StatusConcept mockups. Not a product, not a commitment to any screen.
DataAll names, files, numbers and K-numbers are invented for illustration. "Northbay Devices" is fictional.
Who it's forThe team, and practising consultants evaluating whether this would help them
RequirementsScreen labels such as FR-14.8 point to PRD v2.0

1How to read this document

  • Each phase has its own colour: Phase 1 · Evidence Phase 2 · Drafting Phase 3 · Pilot proof Phase 4 · Workspace Phase 5 · Market
  • Each screen is drawn as a browser or Word window. Red markers like 1 point to the notes under the screen.
  • The dashed box under each screen holds questions for reviewers. Short, blunt answers are the most useful, and "I would not use this" is a valid one. Section 10 collects all the questions in one place.
  • The example throughout: a consultancy preparing a 510(k) for a fictional client's single-use, EO-sterilised infusion set, model IS-200.

2The consultant's journey in one picture

The first two phases cover the whole path from client files to a reviewed Word draft. Later phases add tools around it.

9What never changes, in every phase

Sources

Every fact shows where it came from

File, version and page for client documents; record and date for FDA data. A statement without a source is removed.

Control

The consultant decides

Nothing goes to a client without approval. Versions are never chosen silently. Edits are recorded as yours.

Boundaries

We never file or sign

The consultant fills and files the eSTAR. Signature fields stay blank.

Fit

No new system of record

Files stay in your Dropbox, Box, SharePoint or Drive. Word out. PDF records into your eQMS.

Privacy

Client data stays with the client

Strict separation between clients, no AI training on your data, and deletion per project.
